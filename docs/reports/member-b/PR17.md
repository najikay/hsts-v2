## The three gates

This is the only path by which correctness data reaches a student, so it is the most heavily
gated read in the product.

| # | Condition | How |
|---|---|---|
| 1 | The grade is hers | **Queried, not checked** — `ResultsService.findOwnGrade` filters on the student id in SQL. Deliberately *not* `findByIdUnscoped`, whose new name says why a student path must not touch it |
| 2 | The grade is `APPROVED` | Auto-grading publishes nothing (C-3, S-24). Serving one would show a score her teacher had not stood behind, complete with the answer key |
| 3 | The execution is closed | The one that is easy to forget, because it is the only gate that is not about the person asking. While a sitting is open, handing one student the key hands it to the room |

**All four refusals are one empty `Optional` and one `NOT_FOUND` with one sentence** — not
yours, not approved, still open, never existed. `allFourRefusalsAreIndistinguishable` compares
the four results *to each other* rather than asserting each refuses, because "all four refuse"
is also true of an implementation that refuses them four distinguishable ways, which is the
membership oracle E13.1 exists to prevent.

The service returns an `Optional` rather than an enum of reasons on purpose: an enum would be a
shape inviting the handler to report which gate fired.

**Mutation check.** Replacing gate 3's condition with `false` fails `executionNotClosed`,
`ownApprovedButStillOpen`, `cancelledIsNotClosed` and `allFourRefusalsAreIndistinguishable`.
Reverted immediately; the diff contains no trace of it.

## Your 9.5 ruling, applied

`CheckedForm` gains `attemptStatus` and `actualMinutes`, additively. `StudentGradeRow` stays at
v1.1. The contract records it as the checked-form amendment with your reasoning — that the case
says "open his result and *see*", the seeing happens on the marked paper, solving time belongs
beside the answers it measures, and the list wire pays nothing for data most rows never show.
The note that a "timed out" glyph on the list is separately-priced polish is recorded too.

`actualMinutes` is boxed: not recorded and took no time are different facts.

**The copy says what happened rather than naming a state.** `TIMED_OUT` is a database word, and
a student reading it would reasonably wonder whether her paper counted. It did, and it was scored
like any other (H12.4). She sees *"Time ran out — submitted automatically · 75 minutes"*.

## One assembler, two audiences

`GradeReviewService.answers()` builds the rows — the same method `GRADE_REVIEW_GET` uses. One
place in the product turns an answer key into rows, with two different gates in front of it, so
a change to how a paper is marked cannot land for a teacher and miss a student.

The header is built separately rather than reusing `teacherRow`, because that one carries
`overrideReason`. `CheckedForm` strips it structurally anyway, but handing a student wire a row
that had it would leave the structural strip as the only defence. Two defences everywhere on
this path.

## Three outcomes per question, not two

Right, wrong, and **never answered**. Both of the last two scored zero (§6), so collapsing them
is the tempting simplification — and it would make a timed-out paper unreadable, presenting
every question the student never reached as a mistake she made. That is the seeded `omer.katz`
row and it is 9.5. `unansweredIsNotWrong` is the test.

## ⚑ A finding for you: `ForCheckedForm` now has no readers

The contract says repository reads powering this verb are named `…ForCheckedForm`, and
`CorrectnessLeakGuardTest` carries it as a sanctioned suffix. **No read is named that.** The
assembler is shared with grading, so the read behind it is `findVersionsForGrading`.

I think the sharing is right — one assembler beats two, and the guard's own Javadoc explains
that `ForGrading` exists so grading would not have to lie or be suppressed. But that same
Javadoc says: *"if the feature that licenses it ever goes away, this suffix stops being licensed
and should come back out of this list."* The feature did not go away; it landed differently.

I have **not** removed the suffix from a security guard on my own judgement. Options as I see
them: leave it as a licensed-but-unused name for a future dedicated read, or take it out and
have the contract say the checked form is served through the grading assembler under its own
gates. I lean to the second, because a sanctioned suffix nobody uses is a hole standing open.
